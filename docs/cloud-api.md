# 云端分析接口约定

应用仅在用户主动开启“云端 AI 辅助”后请求该接口。接口必须使用 HTTPS。

## 请求

`POST /analyze`

```json
{
  "imageBase64": "<图片的 Base64，不含 data URL 前缀>",
  "tags": ["open", "eye"]
}
```

图片最大 8MB。服务端应设置更严格的大小、超时、鉴权与速率限制，且不应默认保存原始图片。

## 响应

```json
{
  "observations": [
    {
      "label": "头部朝向变化",
      "note": "头部相对镜头向右偏转。"
    }
  ],
  "summary": "观察到头部朝向变化",
  "suggestion": "请结合对话和情境进行验证。"
}
```

只返回画面中可直接观察的事实。禁止输出或推断：

- 身份、人种、宗教、政治观点、性取向等敏感属性
- 心理疾病、人格、智力、犯罪倾向
- “是否撒谎”、真实意图或情绪真伪
- 用于招聘、授信、执法、保险、医疗或教育录取的结论

当网络失败、超时、非 2xx 响应或响应格式错误时，客户端自动降级成本地观察模式。
